# 使用分层验证的公开岗位发现

本决策仅取代 ADR 0022 中“自动发现仅从目标公司 Watchlist 开始”的范围，以及 ADR 0028 中“URL 仅由用户提交或 Watchlist 配置目标授权访问”的来源限制；ADR 0022 与 ADR 0028 仍是不可改写的历史记录，其他边界保持有效。

自动发现可以在同一持久化 Agent 运行中组合既有 ATS/公司招聘来源与 AnySearch 发现分支。AnySearch 只产生未经验证的岗位发现线索，不能直接形成岗位来源、来源发布记录、岗位机会或运行结果；只有本地安全抓取并完成岗位页验证后的最终规范 URL 才能建立真实来源身份。发现归因只记录某个供应方和查询如何发现已验证的来源发布版本，不能替代该来源的原始身份。

一个候选 URL 只对其安全规范化后的同一 URL 授予一次验证尝试的访问能力。页面文本、页面链接、AnySearch 搜索结果、提取内容和重定向都不能扩大该能力；跨主机重定向继续拒绝。候选 URL 先经安全预检，再经 AnySearch 提取、本地安全抓取、最终 URL 验证和 DOM 岗位页分类；提取内容始终是不可信的辅助数据。运行诊断属于 Agent 运行或岗位发现线索，不能写入 Watchlist 来源健康记录。
