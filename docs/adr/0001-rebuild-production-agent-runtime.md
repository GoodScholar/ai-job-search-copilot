# 重建生产 Agent Runtime

生产系统将原仓库的评分规则、提示词、模板和工作流视为可迁移的领域资产，但不会在服务器上为每位用户运行 Claude Code 仓库实例。画像、岗位发现、匹配、材料生成和投递跟踪将重建为具有明确接口、持久状态和租户隔离的后端模块；这样会增加初期重构成本，但能获得多用户安全、状态一致性、可测试性和可运营性。

## Considered Options

- 为每位用户复制仓库并运行 Claude Code：原型迁移最快，但文件状态、进程权限、并发隔离和升级治理会成为生产风险。
- 重建后端运行时：不能直接复用命令执行方式，但可以保留经过验证的领域规则与工作流意图。
