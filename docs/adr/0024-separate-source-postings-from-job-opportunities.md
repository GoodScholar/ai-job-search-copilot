# 分离来源发布记录与岗位机会

每个招聘网站、ATS、公司官网或用户导入产生独立来源发布记录，保留来源 ID、规范化 URL、原始内容、发现时间、版本和生命周期；多个来源发布记录可以聚合为一个岗位机会。同一来源优先用平台岗位 ID 识别，没有稳定 ID 时使用规范化 URL 与内容指纹；跨来源只在公司主体、标题、地点、部门和描述达到高置信度时自动聚合，猎头、外包和匿名发布默认不自动合并。

## Consequences

- 招聘网站特有字段停留在来源 Adapter 和来源发布记录中，不污染岗位机会接口。
- 内容更新、下架、过期和重新发布形成历史，不覆盖既有匹配与投递证据。
- 中低置信度重复项需要用户确认或保持分离。
