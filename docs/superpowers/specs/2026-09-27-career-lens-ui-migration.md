# 职业透镜设计向现有 Alpha UI 迁移：#66 执行补充规格

本规格将已批准职业透镜视觉迁移到十条现有 Alpha 路由和 Inbox、导入审核、首次推荐旅程、推荐校准四个既有任务态。真实产品契约优先于概念图；概念图仅说明视觉组织。

目标用户是中国市场中高级互联网与 AI 技术求职者。界面必须围绕可信职业资料、真实岗位机会、可追溯推荐和用户审批组织，不能把静态示例解释为用户事实或可执行外部行动。

实现采用冰蓝画布、白色对象、深墨蓝阅读、钴蓝主行动、深海军蓝真实 AI 区、绿色确认、琥珀警示和朱红错误。所有状态同时提供文字；保留现有服务器组合、client view 接缝、SSR/SSE、权限、版本、幂等、轮询和错误恢复。

验收以真实 Web runtime 为准：每条路由和四个任务态须采集 1440×900 与 390×844 截图，验证主对象、空态、关键失败/阻塞、44px 控件、键盘焦点、reduced motion、安全区、无横向溢出和 WCAG AA。每页按布局 30、主视觉 25、字体色彩 20、内容组件 15、移动 10 评分，至少 95 分且关键缺项为零。

不在本 Issue 实现材料生成、审核后台、外部投递、投递进展、文本面试、公开分享或账户删除；不新增 API、schema、数据或生产依赖。
